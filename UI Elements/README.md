# Astra UI (Expo)

Minimal midnight celestial UI for:
- Home
- Palmistry (camera overlay guide + saved hands + chat)
- Tarot (animated flip + reveal + show more)
- Auth + credits (gating via modal + persisted state)

## Setup
```bash
npm install
npm run start
```

## Notes
- This is UI-first (no backend). Replace mock data/services in `src/services/*`.
- Palm camera overlay uses SVG guide (assets/svg/palm-guide.svg).
